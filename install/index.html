給健康中心護理人員的安裝圖解

SHIS Local 安裝與首次啟用

依序完成 12 個步驟即可在健康中心主機建立系統，並讓第二台校內電腦透過瀏覽器連線。

版本 1.2.49Windows 10／11 64 位元預設 TCP 3000不需另外安裝 PostgreSQL
安裝前請確認使用具本機系統管理員權限的 Windows 帳號；主機接有線網路、不可長時間睡眠；至少保留 4 GB 可用磁碟空間。

可以做

  • 在健康中心主機安裝一次
  • 第二台電腦只使用瀏覽器連線
  • 學生名冊在初始化後再匯入

不要做

  • 不要把 TCP 3000 開放到網際網路
  • 不要公開一次性初始化金鑰
  • 不要手動刪除 ProgramData 的資料庫
01

安裝前

確認安裝檔與檢查碼

  1. 把安裝程式、SHA-256 檢查碼及本教學放在同一資料夾。
  2. 確認版本與學校管理員提供的正式版本相同。
  3. 若檔案來源不明或檢查碼不一致，停止安裝。
02

啟動安裝

以系統管理員身分執行

  1. 先將壓縮檔完整解壓縮。
  2. 在 .exe 安裝檔按滑鼠右鍵。
  3. 選擇「以系統管理員身分執行」。
03

Windows 確認

允許安裝程式變更裝置

  1. 確認畫面中的應用程式是 SHIS Local Setup。
  2. 再次確認檔案是由校內正式來源取得。
  3. 按「是」繼續。
04

安裝精靈

閱讀內容並開始安裝

  1. 關閉其他 SHIS Local 視窗。
  2. 閱讀畫面中的版本與安裝內容。
  3. 按「下一步」。
05

程式目錄

保留預設安裝位置

  1. 保留 C:\Program Files\SHIS Local。
  2. 不要安裝在桌面、下載或網路磁碟。
  3. 按「安裝」。
06

自動設定

等待資料庫與服務建立完成

  1. 保持主機開機，不要重新啟動。
  2. 安裝通常需要數分鐘，硬碟較慢時可能更久。
  3. 等待健康檢查完成後再操作網站。
正常現象進度列停留一段時間不一定是當機。若超過 15 分鐘完全沒有變化，再依本頁「故障排除」處理。
07

安裝完成

查看連線資訊與一次性初始化金鑰

  1. 安裝完成後保留自動開啟的連線資訊視窗。
  2. 記下 Local URL 與 LAN URL。
  3. 初始化時從此處取得一次性金鑰，不要拍照或傳送。
一次性金鑰不是密碼它只能建立系統一次，不能登入、不能重設密碼；初始化完成後即失效。
08

首次啟用

填寫學校與正式帳號

  1. 在主機開啟 http://localhost:3000/。
  2. 填寫學校名稱、學校代碼、管理員及護理師資料。
  3. 兩個帳號使用不同密碼，每組密碼輸入兩次。
  4. 輸入一次性初始化金鑰。
09

確認提交

預覽後正式建立系統

  1. 確認學校名稱、帳號及系統自動判斷的初始學期。
  2. 如有錯誤，按「返回修改」。
  3. 確認無誤後按「正式建立系統」。
  4. 等待系統建立首次 PostgreSQL 備份。
10

開始使用

使用個人帳號第一次登入

  1. 管理員使用管理員帳號登入；護理師使用護理師帳號登入。
  2. 若系統要求更新密碼，輸入新密碼兩次。
  3. 完成後應進入工作台。
11

建立學生資料

匯入第一份學生名冊

  1. 開啟「資料匯入匯出 → 學生名冊匯入」。
  2. 確認目標學期，選擇 .xls、.xlsx 或 .csv。
  3. 查看新增、更新、缺漏與錯誤列。
  4. 錯誤為 0 後，輸入本人密碼正式匯入。
12

校內使用

讓第二台校內電腦連線

  1. 在主機的連線資訊找到 LAN URL。
  2. 在第二台校內電腦的瀏覽器輸入完整網址。
  3. 確認登入畫面出現，再以個人帳號登入。
  4. 無法連線時執行 Test-NetConnection 主機IP -Port 3000。
!

先自己檢查

常見問題與處理順序

安裝超過 15 分鐘或出現 Runtime error

不要重複安裝多次。記下錯誤碼，確認 C:\ProgramData\SHIS Local\logs\install.log 是否存在，再由資訊管理人員檢查 TCP 3000 是否被占用。

開啟 localhost:3000 顯示空白或拒絕連線

先等待主機開機後 1 至 2 分鐘，再從開始功能表執行「SHIS Local 系統檢查」。四個服務應為執行中：SHISLocalPostgreSQL、SHISLocalWeb、SHISLocalApi、SHISLocalGateway。

第二台電腦無法連線

確認主機未睡眠、IP 沒有改變、兩台電腦位於可互通的校內網段，且 Test-NetConnection 主機IP -Port 3000 顯示 True。

無法開啟 connection-info.txt

請由安裝主機的系統管理員開啟。不要自行變更整個 C:\ProgramData\SHIS Local 資料夾權限，也不要把檔案複製到公開資料夾。

初始化金鑰找不到或無效

確認讀取的是同一台主機的 `connection-info.txt`。若系統已初始化，金鑰失效屬正常現象，請直接使用正式帳號登入。

初始化顯示「系統處理失敗」或首次備份失敗

先重新整理一次。若出現登入畫面，表示系統資料已建立，請登入管理員帳號並立即到「資料備份與還原」建立首次備份；若仍停在初始化精靈，系統會先檢查 PostgreSQL 備份工具與備份目錄，不會在檢查失敗時寫入正式資料。請記下畫面上的要求編號，交由資訊管理人員查看 C:\ProgramData\SHIS Local\logs\SHISApiService.out.log 與 SHISApiService.err.log。

交給資訊管理人員

求助時請提供這些資料

可以提供

  • 安裝程式版本
  • 發生時間與操作步驟
  • 已遮蔽帳號、IP 與學生資料的錯誤截圖
  • logs 內相關記錄檔
  • 系統檢查結果

不可提供

  • 一次性初始化金鑰
  • 管理員或護理師密碼
  • config 內的密鑰與資料庫密碼
  • 完整學生名冊或健康資料
  • 整個 database 資料夾
