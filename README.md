# 學生健康資訊系統操作手冊

SHIS Local 離線操作手冊，供學校健康中心操作人員閱讀及協作平台嵌入使用。

- 對應系統版本：1.2.31
- 手冊版本：1.2
- 程式開發者：桃園市青溪國小 黃志豪
- 英文署名：Qingxi Elementary School - Gavin Huang

## 個資安全

網站所使用的操作截圖已裁除或使用不透明遮罩處理直接識別資料；儲存庫不包含學生名冊、健康資料、帳號密碼、資料庫或 SHIS Local 系統原始碼。

功能概念、傷病登錄流程、健康中心業務方法與資料欄位延伸自原有傷病系統及既有校務需求，不主張為開發者的著作權。開發者的著作權主張限於自行完成且具原創性的程式碼、目的碼、程式模組及其具體程式表達。第三方套件、開放原始碼程式及原有系統內容分別適用原權利人或原授權條款。
